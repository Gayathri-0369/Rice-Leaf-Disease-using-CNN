# Rice-Leaf-Disease-using-CNN
Developed a Rice Leaf Disease Detection system using Python and Deep Learning to classify rice leaf images into Leaf Smut, Brown Spot, and Bacterial Leaf Blight. Implemented CNN, MobileNetV2, and EfficientNetB0 using TensorFlow/Keras, with image preprocessing, data augmentation, and Grad-CAM explainability. Achieved 94.44% test accuracy.
